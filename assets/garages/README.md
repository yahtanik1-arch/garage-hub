# Изображения тестового бокса

Два сгенерированных изображения вымышленного гаража, не фотографии реальной площадки.
Созданы встроенным image_gen 19 ноября 2026. JPEG 1280×720, сжаты для сайта.
В БД: `local:test-overview-v1.jpg`, `local:test-workbench-v1.jpg`.
API отдаёт только известные каталогу ID и разрешённые имена картинок из этой папки;
Telegram и внешние фотосервисы не нужны. При замене картинки используйте новое имя версии.

Промпты: реалистичный обычный гараж на одну машину в Москве, белые кирпичные стены,
серый бетонный пол с закрытой смотровой ямой, красный инструментальный шкаф и верстак
с тисками, естественный свет, без людей, автомобилей, логотипов и текста.
Первый ракурс — общий вид со входа; второй — верстак и инструменты крупнее.
